## A. Clinical audit

The live profile page does not call a `paragon_api.py`. There is no such file. Scores reach the screen from `db/paragon_scores_export.json`, imported by `services/apiService.ts` and by `components/figurat-politike/PoliticiansDatabase.tsx`. `vite.config.ts` reads the same file when it answers `/api/v1/politicians/:id`. `api/v1/politicians.py` also reads that export when the database view is missing, and it previously filled a missing `dynamicScore` with 50.

`components/figurat-politike/useParagonRatings.ts` started at `enabled = true` and turned scores off only after a successful fetch of `public/paragon-ratings.json` with `enabled: false`. A failed fetch left scores on. That is fail-open. The file on `010f971` had `enabled: true`.

`services/paragonEngine.ts` built integrity, vulnerability and behavioural labels from a hash of the name, and it filled a missing score vector with `[80, 52, 30, 45, 80, 40, 60]`. Those labels are not measurements. They are removed from the public return and the hash function now lives only in `services/paragon_hash_quarantine.ts`, which no page imports.

`services/paragon_scoring_engine.py` is the formula module. `scripts/apply_official_paragon_scores.py` is what wrote the export. `services/paragon_scoring_service.py` and `services/parliament_roster_service.py` are the database and roster services. The roster files were not edited.

The fingerprint route in `api/v1/politicians.py` already returned null scores. The cards route and the static frontend did not. The static fallback in `fetchPoliticianProfile` returned the export, including composites, when the API failed.

Construct problems, applying to every profile scored this way, not only vip55:

- D1 is plenary presence, stored in a field named `committee_attendance_pct`.
- D2 is the share of roll calls with a vote, labelled accountability.
- D3 is the party’s district vote share, labelled representation.
- D4 is speech volume, labelled assertiveness.
- D5 is committee-header attendance, labelled governance.
- D6 is agreement with the parliamentary-group majority, labelled cohesion.
- D7 is keyword concentration, labelled narrative.

The arithmetic that turns those inputs into the stored numbers is reproducible. The decision to publish them as a PARAGON rating is not defended. The gate is therefore closed.
